# Day 5 — Executive Overview Dashboard

## Objective

Build the first interactive Power BI dashboard page to provide a high-level overview of ride-hailing trips, revenue, demand, and operational performance.

## Dashboard Page

**Page Name:** Executive Overview

## KPI Cards

The following KPI measures were added:

- Total Trips
- Total Revenue
- Average Fare
- Cancellation Rate
- Average Driver Rating

## Dashboard Visuals

--> 1. Monthly Trips Trend
- Line chart
- Axis: Month Name
- Measure: Total Trips
- Used to analyze monthly trip demand.

--> 2. Monthly Revenue Trend
- Line chart
- Axis: Month Name
- Measure: Total Revenue
- Used to analyze monthly revenue performance.

--> 3. Trip Status Analysis
- Donut chart
- Categories: Completed and Cancelled
- Measure: Total Trips
- Used to compare completed and cancelled trips.

--> 4. Weekday vs Weekend Demand
- Column chart
- Axis: Day Type
- Measure: Total Trips
- Used to compare weekday and weekend demand.

## Interactive Slicers

The dashboard includes:

- Trip Status
- Payment Type
- Month Name
- Pickup Location

These slicers allow users to interactively filter the dashboard.

## Dashboard Formatting

- Added professional dashboard title and subtitle.
- Applied consistent blue and dark navy color theme.
- Used orange to highlight cancelled trips.
- Applied light background for improved readability.
- Aligned KPI cards and dashboard visuals.
- Organized slicers at the bottom of the page.

## Validation

- Verified KPI values.
- Verified monthly trend charts.
- Verified Trip Status and Day Type visuals.
- Tested slicer interactions.
- Confirmed Month Name is sorted chronologically using Month Number.
- Checked overall dashboard alignment and readability.

## Conclusion

The Executive Overview dashboard provides a consolidated view of ride-hailing business performance and allows users to interactively analyze trips, revenue, demand patterns, and operational metrics.
