# Day 04 — DAX Measures & KPI Development

## Objective

Create and validate core DAX measures required for the Urban Ride-Hailing Fleet Optimization & Revenue Dashboard.

## 1. Core DAX Measures

The following measures were created:

1. Total Trips
2. Completed Trips
3. Cancelled Trips
4. Total Revenue
5. Average Fare
6. Average Trip Distance
7. Average Trip Duration
8. Cancellation Rate
9. Revenue per Trip
10. Revenue per KM
11. Peak Hour Demand
12. Weekend Demand %
13. Total Distance
14. Completed Trip Revenue
15. Average Driver Rating

## 2. DAX Concepts Used

- COUNTROWS
- SUM
- AVERAGE
- CALCULATE
- DIVIDE
- MAXX
- VALUES
- Filter context

## 4. Validation

All 15 DAX measures were tested using Power BI visuals.

The measures returned values without DAX errors and were validated against the underlying dataset.

Percentage measures were formatted appropriately.

## 5. Conclusion

The core DAX layer for the project has been successfully created and validated.

The model is now ready for dashboard development and business analysis.
