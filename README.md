\# Urban Ride-Hailing Fleet Optimization \& Revenue Dashboard



\--> Project Overview



An end-to-end Power BI data analytics project focused on analyzing urban cab demand, driver utilization, revenue, cancellations, and operational performance.



\--> Business Objective



The project aims to identify demand patterns, peak hours, high-demand locations, driver utilization, revenue trends, and cancellation behavior to support data-driven operational decisions.

\- Power Query

\- DAX

\- Git \& GitHub
